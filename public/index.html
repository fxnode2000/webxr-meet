Create a room

Make one with the Blender template (also avatar_kit.py and instructions). The file is checked in your browser and shared only with the others in the room.

You will be asked to allow your microphone. Headphones are recommended on a desktop.

Room PIN

Run an Amiga in the room

The Amiga runs in your browser and everyone sees and hears it on the kitchen TV. Up to two friends can join on joysticks. You keep the keyboard.

Without a Kickstart file the free AROS replacement is used. It runs many games but not all. Floppy disk images only. Use disks you own or that are freely distributable.

Run an arcade game in the room

The game runs in your browser (you are player 1, on the keyboard) and everyone sees and hears it on the kitchen TV. Up to two friends can join as players 2 and 3 with a gamepad, keyboard or VR controllers. Keep this tab visible while the game runs.

Games are not included. Use ROMs you own or that are freely distributable. The zip has to match the emulator's version of the game; if it does not start, try the other emulator. Controls: arrows, Z X C and A S D for the buttons, 1 = Start, 5 = insert coin.
